# Cybersecurity Log Analysis

## Project Overview

This project demonstrates my ability to analyze security logs and identify
potentially suspicious authentication activity.

I used sample security log data to investigate failed login attempts,
identify patterns, and document security findings.

## Objectives

- Analyze authentication logs
- Identify repeated failed login attempts
- Look for unusual login activity
- Document security findings
- Practice basic incident investigation techniques

## Tools & Technologies

- Linux
- Python
- Security logs
- SIEM concepts
- Command-line tools

## Investigation Process

1. Reviewed the sample authentication logs.
2. Identified failed login attempts.
3. Looked for repeated attempts from the same source.
4. Investigated unusual patterns.
5. Documented the findings.
6. Considered possible security recommendations.
